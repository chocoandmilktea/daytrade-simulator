## 運用ルール

- **追記専用**。過去行の書き換え・削除は行わない。誤りがあった場合は訂正行を新たに末尾へ追加する
- 新しい行は**表の末尾**に追加する（日付の昇順）
- `種別`：`env`（環境変数変更）/ `deploy`（再デプロイ）/ `merge`（PRマージ）/ `config`（設定変更）
- `データ影響`：`有`（収集・保存されるデータの内容や件数が変わる）/ `無` / `不明`
- 日付は JST。時刻が判断に関わる場合のみ `内容` 欄に併記する
