# 利確+1.5%・損切り-0.75%の売り方で見た候補銘柄の成績 検証結果

- 生成: `node scripts/exit-rule-check.mjs`（実行日 2026-09-23）
- 候補銘柄の作り方: `scripts/sector-select-check.mjs`（PR #85）と同じ
- 銘柄一覧: JPX 東証上場銘柄一覧（20260831 時点）のうち、プライム・スタンダード・グロースの内国株式 3707銘柄
- 日足: Yahoo Finance（range=3y）
- 米国取引日: 2023-09-25 〜 2026-09-23（751日）
- 日本取引日: 2023-09-19 〜 2026-09-18（734日）
- 検証対象日: 701日（2023-09-27 〜 2026-09-18）

売り方: T当日の始値 O で買い、利確ライン O × 1.015・損切りライン O × 0.9925 を T当日の始値・高値・安値・終値で判定する。

- パターン1: 高値が利確ライン以上で、安値が損切りラインより上 → +1.5%
- パターン2: 安値が損切りライン以下で、高値が利確ラインより下 → -0.75%
- パターン3: 高値が利確ライン以上で、かつ安値が損切りライン以下 → 厳しめは -0.75%、甘めは +1.5%
- パターン4: どちらにも届かない → 終値 ÷ 始値 − 1
