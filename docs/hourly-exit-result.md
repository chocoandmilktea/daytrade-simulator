# 1時間足で判定した利確+1.5%・損切り-0.75%の売り方の成績 検証結果

- 生成: `node scripts/hourly-exit-check.mjs`（実行日 2026-09-24）
- 候補銘柄の作り方・グループの定義: `scripts/exit-rule-check.mjs`（PR #86）と同じ
- 銘柄一覧: JPX 東証上場銘柄一覧（20260831 時点）のうち、プライム・スタンダード・グロースの内国株式 3707銘柄
- 日足: Yahoo Finance（range=3y）。日本取引日: 2023-09-25 〜 2026-09-24（731日）
- 1時間足: Yahoo Finance（interval=60m、range=730d）。時刻は api/daily.js と同じく gmtoffset を加算して日本時間に直す
- 1時間足で判定できる期間: 2023-09-26 〜 2026-09-24（7203.T の1時間足の最古日〜最新日）
- 期間中の日本取引日: 730日（うち検証対象日 701日、2023-09-27 〜 2026-09-18）
- 1時間足の取得対象: 期間中に一度でも候補に選ばれた 2956銘柄（取得失敗 0銘柄。上場が新しく range=730d が 422 になったため range=2y で取り直した銘柄 75銘柄）

売り方: T当日の日足の始値 O で買い、利確ライン O × 1.015・損切りライン O × 0.9925 とする。T当日の1時間足を時刻順に見て、最初に「高値が利確ライン以上」または「安値が損切りライン以下」になった足で決着させる。

- 利確で決着: その足で利確ラインだけに届いた → +1.5%
- 損切りで決着: その足で損切りラインだけに届いた → -0.75%
- 同じ足で両方に到達: どちらが先か不明 → 厳しめは -0.75%、甘めは +1.5%
- どちらにも届かず大引け: どの足でも届かない → T当日の日足の終値 ÷ 始値 − 1
