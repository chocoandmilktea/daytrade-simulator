# スコアの作り方を変えた場合の上位10の成績 試算結果

- 生成: `node scripts/score-variants-check.mjs`（実行日 2026-09-25）
- 検証日・候補・15分足の切り方・スコアの計算・売り方の判定: `scripts/score-parts-check.mjs`（PR #90、8:50）と `scripts/score-parts-1000-check.mjs`（PR #91、10:00）と同じ。候補は8:50時点のもの（前日の確定値で、出来高上位40と、値上がり率上位20（出来高が全銘柄の中央値の1.5倍以上のもの）を重複なしで並べたもの）で、10:00も同じ候補を使う
- 銘柄一覧: JPX 東証上場銘柄一覧（20260831 時点）のうち、プライム・スタンダード・グロースの内国株式 3707銘柄
- 15分足: Yahoo Finance（interval=15m、range=60d）。今回取得できた期間 2026-06-29 〜 2026-09-25（PR #88・#89 は 2026-06-26 〜 2026-09-24）。取れなかった日: 2026-06-26。2026-06-26 の欠けは PR #90・#91 と同じ扱い（600本以上の条件を判定するときに、その日の足があれば増えていた本数を足す）。PR #88・#89 の窓にこの日が入っていた検証日は、8:50で 7日、10:00で 6日（窓が短いまま計算した銘柄日: 8:50 409件、10:00 350件）
- スコア: 自動スキャン（`api/_scan.js`）と同じく VIX なし・過去の的中率の統計なし。TOPIX前日比は 1306.T（TOPIX 連動ETF で代用） の日足（調整後終値）で、T当日の前日の値（8:50・10:00とも同じ値）
- 時計: 8:50は対象日の 8:50、10:00は対象日の 10:00（日本時間）に固定（`currentSessionDate("JP")` のずれ: 8:50 0日、10:00 0日。寄り付き後扱いになった8:50の件数 0、寄り付き前扱いになった10:00の件数 0）
- 部品ごとの点数: `analyzeStock()` の返り値の `breakdown` から取り出した（部品の点数の合計とスコアの不一致 0件）。`api/stock.js` の `toLocalDates()` の写しは実行時に一字一句同じであることを確かめた（一致）

損益の定義（どちらも往復コスト0.1%を引いた値）:

- 買値: 8:50は T当日の日足の始値（寄り付き）。10:00は10:00開始の15分足の始値
- 損益A（売り方ルール）: 利確ライン 買値 × 1.015・損切りライン 買値 × 0.9925。買った足から時刻順に15分足を見て、先に届いた方で決着。どちらにも届かなければ T当日の日足の終値で手仕舞い。同じ15分足で両方に届いた場合は PR #88 の按分（損切りが先 2/3・利確が先 1/3 の加重平均）
- 損益B（大引けまで持つ）: T当日の日足の終値 ÷ 買値 − 1 − 0.1%
- 勝率（損益A）: 損益Aがプラスだった割合。同じ足で両方に届いた件は 1/3 勝ちとして数える（PR #88 と同じ）
- 前日騰落率: 前日終値 ÷ 前々日終値 − 1（Yahoo の日足の調整後終値。`scripts/score-parts-check.mjs` と同じ）
- 当日騰落率: 10:00時点の現在値（9:45開始の15分足の終値）÷ 前日終値（Yahoo の日足の終値）− 1（`scripts/score-parts-1000-check.mjs` と同じ）
- グループ2B: 前日値上がり率上位20から入った候補
